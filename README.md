# Papa Kid Gents Salon

Premium Next.js website for Papa Kid Gents Salon in Al Warqa 1, Dubai.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Vercel Settings

- Framework Preset: `Next.js`
- Build Command: `npm run build`
- Output Directory: leave empty
- Install Command: leave default

## Update Salon Contact Details

Edit `lib/siteData.js` to replace the placeholder phone and WhatsApp number with the salon's official number.
